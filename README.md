# SOS Oficina

Juego interactivo de diagnóstico técnico creado por **Angelin Espinoza** para demostrar competencias en soporte IT, sistemas, redes y seguridad.

## Jugar

La versión pública estará disponible en:

https://angeline-jose-molina-espinoza.github.io/sos-oficina/

## Incidencias incluidas

- Diagnóstico de una dirección APIPA y problemas DHCP.
- Resolución de nombres y diagnóstico DNS.
- Identificación y respuesta ante un intento de phishing.

## Tecnologías

React, TypeScript, Vite y CSS.
